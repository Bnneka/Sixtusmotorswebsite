# SIXTUS MOTORS NIGERIA LIMITED

Next.js 16 website with Home, Services, Fleet, About and Contact pages.

## Run
With Node.js 20.9+ installed:
    npm install
    npm run dev
Open http://localhost:3000.
For production: npm run build, then npm start.

Start-Website.ps1 can use the bundled Codex Node runtime on this computer.
